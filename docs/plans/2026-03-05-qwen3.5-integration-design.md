# Qwen3.5 Integration Design

## Summary

Add Qwen3.5 unified vision-language model support to the dataset validator.
Three backends: HuggingFace direct (local), vLLM server, Ollama server.
All model sizes from 0.8B to 397B-A17B.

## Key Architecture Difference

Qwen3.5 is a **unified model** — not a separate VL variant. It uses:
- `AutoModelForCausalLM` (not `AutoModelForVision2Seq` like Qwen2/3-VL)
- `AutoProcessor` for multimodal inputs
- `image_url` content type in messages (not `image` with PIL objects)
- New family: `qwen3_5`

## Changes

### 1. `config/models.yaml` — Add 8 models

| Key | HF ID | Params | VRAM (INT4) | VRAM (FP16) |
|-----|--------|--------|-------------|-------------|
| qwen3.5-0.8b | Qwen/Qwen3.5-0.8B | 0.8B | ~1GB | ~2GB |
| qwen3.5-2b | Qwen/Qwen3.5-2B | 2B | ~2GB | ~4GB |
| qwen3.5-4b | Qwen/Qwen3.5-4B | 4B | ~3GB | ~8GB |
| qwen3.5-9b | Qwen/Qwen3.5-9B | 9B | ~6GB | ~18GB |
| qwen3.5-27b | Qwen/Qwen3.5-27B | 27B | ~16GB | ~54GB |
| qwen3.5-35b-a3b | Qwen/Qwen3.5-35B-A3B | 35B (MoE, active 3B) | ~8GB | ~20GB |
| qwen3.5-122b-a10b | Qwen/Qwen3.5-122B-A10B | 122B (MoE, active 10B) | ~30GB | ~80GB |
| qwen3.5-397b-a17b | Qwen/Qwen3.5-397B-A17B | 397B (MoE, active 17B) | ~60GB | ~150GB |

All use `family: "qwen3_5"`, `chat_template: "qwen3_5"`.

### 2. `core/evaluator.py` — qwen3_5 family support

- `load_vlm()`: Add `qwen3_5` branch using `AutoModelForCausalLM`
- New `_build_messages_qwen3_5()`: Uses PIL Image objects directly with processor
- `evaluate_single()`: Add `qwen3_5` branch for inference

### 3. `core/ollama_client.py` — New file

Separate Ollama OpenAI-compatible client:
- `evaluate_single_ollama()`: Send base64 images via OpenAI chat completions API
- `check_server_health()`: Ollama health check
- Model name mapping: `qwen3.5-9b` → `qwen3.5:9b` (Ollama tag format)
- Default URL: `http://localhost:11434`

### 4. `core/parallel.py` — Add ollama backend

- `_run_ollama()`: Sequential evaluation via Ollama API (same pattern as `_run_vllm`)
- `run_parallel_evaluation()`: Add `backend="ollama"` dispatch

### 5. `validate_dataset.py` — CLI updates

- `--backend` choices: `["local", "vllm", "ollama"]`
- `--ollama-url` argument (default: `http://localhost:11434`)
- Help text: Add all Qwen3.5 models to supported models list

### 6. `serve_vllm.py` — No changes needed

vLLM server already resolves model names via models.yaml, so Qwen3.5 models work automatically after adding to config.

## Backend Usage Examples

```bash
# Local (HuggingFace direct)
python validate_dataset.py --model qwen3.5-9b --backend local ...

# vLLM server
python serve_vllm.py --model qwen3.5-9b
python validate_dataset.py --model qwen3.5-9b --backend vllm ...

# Ollama
ollama pull qwen3.5:9b
python validate_dataset.py --model qwen3.5-9b --backend ollama ...
```
